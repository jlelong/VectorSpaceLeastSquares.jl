# VectorSpaceLeastSquares

```@eval
using ..VectorSpaceLeastSquares
using Markdown
v = string(pkgversion(VectorSpaceLeastSquares))
md"This is the documentation for release $v"
```

This package aims at computing the least squares approximation within a vector space of functions. It solves the following optimization problem

$$\inf_{\alpha \in \mathbb{R}^d} \sum_{m=1}^M \left(\sum_{i=1}^L \alpha_i g_i\circ\varphi(x_m) - y_m\right)^2 + \lambda |\alpha|^2$$

where

- The sequence $(x_m, y_m)_{1 \le m \le M}$ is the training data: $y_m \in \mathbb{R}$ is the expected value at the point $x_m \in \mathbb{R}^d$.
- The function $\varphi: \mathbb{R}^d \to \mathbb{R}^d$ is the [transformation](transformations.md) to be be applied to the input data before solving the least squares problem
- For $i = 1, \dots, L$, $g_i : \mathbb{R}^d \to \mathbb{R}$. The family $(g_1, \dots, g_L)$ must be a free family to ensure that the least squares problem is not ill-posed. We call the family a [basis](basis.md) in the following.
- The parameter $\lambda \ge 0$ is the Ridge penalization parameter. The default value is $\lambda = 0$.

Let $\mathcal{V}$ be the vector space generated by the functions $(g_1\circ\varphi, \dots, g_L\circ\varphi)$, this package computes the best least squares approximation of the unknown function $x \longmapsto y$ inside $\mathcal{V}$ up to a transformation $\varphi$.

This package can also be used with kernels instead of the standard functions $g_i$. In this case, the least squares problem writes

$$\inf_{\alpha \in \mathbb{R}^M} \sum_{m=1}^M \left(\sum_{i=1}^M \alpha_i K(\varphi(x_i), \varphi(x_m)) - y_m\right)^2 + \lambda |\alpha|^2$$

where $K:\mathbb{R}^d \times \mathbb{R}^d \to \mathbb{R}$  and the vector space $\mathcal{V}$ is generated by the functions $(K(\varphi(x_i), \varphi(\cdot)))_{i=1,\dots,M}$. Note that in this case, $\mathcal{V}$ depends on the training points. See the [kernel basis section](kernel.md).

## Installation

VectorSpaceLeastSquares is compatible with Julia version 1.11 or later.

To get the VectorSpaceLeastSquares package installed, execute the following Julia command:

```julia
import Pkg
Pkg.add("VectorSpaceLeastSquares")
```
